# LoFNetwork

Analysis code for **"Gene functional-state covariance reveals modular structure in the *Arabidopsis thaliana* dispensable genome"** (Bird, Zhao, Kliebenstein & Monroe).

Preprint: *bioRxiv DOI to be added*

---

**Code is being organised for release and will be added here shortly.** 


| Script | Covers |
|---|---|
| `GlobalNetwork.Rmd` | Network construction, topology and null models, Leiden community detection and resolution selection, membership stability, k-shell decomposition, cis/trans edge composition, integrated functional enrichment, inter-community mixing, accession-level community burden |
| `LoF_PCA.R` | Descriptive analyses and Figure 1 — loss-of-function counts, geographic distribution, principal component analysis |
| `LoF_Pair_enrichment.Rmd` | Pairwise coexpression and GO annotation overlap against permuted null sets |
| `NAm_HPG1_analysis.Rmd` | Characterisation of the North American (HPG1) lineage |
